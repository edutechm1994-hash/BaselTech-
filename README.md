# متجر النخبة — متجر إلكتروني

موقع متجر إلكتروني عربي (RTL) مبني بـ HTML و CSS و JavaScript خالص، بدون أي مكتبات خارجية.

🌐 **الموقع المنشور:** https://edutechm1994-hash.github.io/BaselTech-/

## المميزات

- واجهة عربية كاملة من اليمين إلى اليسار (RTL) ومتوافقة مع الجوال
- عرض المنتجات مع تصفية حسب الأقسام (سماعات، ساعات ذكية، إكسسوارات)
- سلة تسوق كاملة: إضافة، زيادة/تقليل الكمية، حذف، وحفظ تلقائي في المتصفح (localStorage)
- صفحة إتمام طلب بنموذج (الاسم، الجوال، المدينة، العنوان) مع توليد رقم طلب
- تصميم متجاوب مع شاشات مختلفة
- نشر تلقائي إلى GitHub Pages عبر GitHub Actions

## التشغيل محليًا

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## البنية

```
index.html                      — هيكل الصفحة
styles.css                      — التنسيقات
app.js                          — منطق المنتجات والسلة والطلب
.github/workflows/deploy.yml    — نشر تلقائي إلى GitHub Pages
```

## ملاحظة

الطلبات تُعالج حاليًا في الواجهة الأمامية فقط (عرض توضيحي). لربط بوابة دفع حقيقية أو حفظ الطلبات في خادم، يلزم إضافة واجهة خلفية.
